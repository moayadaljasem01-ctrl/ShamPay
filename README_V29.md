# ShamPay v29 — تجربة تجريبية فقط

- إضافة رصيد افتراضي من 1 إلى 1,000,000 ل.س لكل عملية وبحد إجمالي 10,000,000 ل.س، دون بوابات دفع أو بيانات بطاقات.
- تسجيل الإضافة في سجل العمليات المحلي. جميع الأرصدة محفوظة في localStorage وليست أموالاً حقيقية.
- شاشة استلام QR مع مبلغ اختياري، ونسخ أو مشاركة النص التجريبي. الرمز يحوي رقم الحساب التجريبي، لذا لا تشاركه علناً.
- قارئ QR التجريبي يقبل الصيغة القديمة والجديدة ذات المبلغ الاختياري.
- سجل النشاطات يجمع أحداث تسجيل الدخول وتغييرات الأمان المسجلة محلياً، دون بيانات موقع مخترعة أو حذف للسجل.
- لا يُستخدم لأي نشاط مالي حقيقي ولا يُعتمد كأمان إنتاجي.
