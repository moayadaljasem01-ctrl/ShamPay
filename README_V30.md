# ShamPay v30 — DEMO only

- Transaction receipts include DEMO status, reference, date, share and browser Print/Save as PDF (iPhone: Share/Print options depend on Safari).
- Empty states for transactions and notifications.
- Transaction search, category and date-range filters.
- Privacy auto-mask on app background.
- Optional *simulated* biometric lock: PIN unlock only, **not** actual Face ID or Touch ID.
- Offline QR viewing after successful PWA cache installation; **no offline payment or settlement**.
- All data is fictional and stored locally in this browser.

## Manual tests
1. Load with internet and create a demo account; test a transaction and receipt/share/print.
2. Filter by category, search reference, filter by date.
3. Enable privacy masking, background and resume, check hidden balance.
4. Enable simulated lock, background and resume, check PIN unlock.
5. Load QR online, then go offline and reload to verify cached resources.
