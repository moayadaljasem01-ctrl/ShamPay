# ShamPay v34 — Transfers & Interactive Demo

- Distinct SVG arrows for Send and Receive (including quick actions).
- Detailed transaction entries: counterparty, amount, date, reference, receipt.
- Existing demo transfers continue to require a second locally registered demo account, OTP and PIN.
- New explicit fictional incoming-funds simulator on Receive screen, capped at 1,000,000 SYP per event and 10,000,000 SYP total. **Not a QR payment.**
- One-tap copy of demo wallet identifier with toast and fallback. No real IBAN is issued.
- Premium subtle borders, mobile spacing and dark mode.
- All data is browser-local. Never use real personal or financial details.
