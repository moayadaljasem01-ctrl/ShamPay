# ShamPay v35 — Liquid Glass Navigation

- Floating dark-glass five-tab navigation, RTL/LTR aware.
- One optical glass lens travels between tabs with stretch, overshoot and settling.
- QR tab uses scanner corners, not the generic four-square glyph.
- Supports safe area, reduced motion, light/dark themes, responsive widths, keyboard focus.
- Navigation stays functional with no Web Animations support.
- PWA is DEMO only; CSS approximates the iOS native Liquid Glass effect.

QA: test on iPhone Safari and installed PWA; especially rapid taps, rotation, RTL/English, dark mode and iOS accessibility reduced motion.
